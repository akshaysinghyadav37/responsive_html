# यादव परिवार — डिजिटल विवाह निमंत्रण

बिना बिल्ड और बिना सर्वर के चलने वाली हिंदी वेबसाइट (HTML + CSS + JavaScript)।

फ़ाइलें: `index.html`, `style.css`, `script.js`, `ganesh.svg`, `README.md`

## 1. GitHub Pages पर होस्ट करना
1. github.com पर निःशुल्क खाता बनाएँ और नया **Public** repository बनाएँ (जैसे `vivah-nimantran`)।
2. **Add file → Upload files** से ऊपर की सभी फ़ाइलें अपलोड करें और **Commit** करें।
3. **Settings → Pages** खोलें। *Source* में **Deploy from a branch**, *Branch* में `main` और फ़ोल्डर `/ (root)` चुनकर **Save** करें।
4. 1–2 मिनट बाद लिंक दिखेगा: `https://आपका-यूज़रनेम.github.io/vivah-nimantran/` — यही स्थायी लिंक है।

## 2. सामग्री बदलना
नाम, वर्तनी, परिवार के सदस्य और आशीर्वादकर्ताओं की सूची केवल `script.js` के ऊपर वाले `CONFIG` और `DATA` में बदलें।
- परिवार की श्रेणियों (बड़े पापा/चाचा, बुआ, मामा, स्वर्ग से आशीर्वाद) में `items: []` में नाम जोड़ें, जैसे `{ name: "नाम", role: "रिश्ता", children: [ ... ] }`। खाली रहने पर "शीघ्र जोड़े जाएँगे" दिखता है।
- दादा–माता–पिता के वृक्ष में दादाजी को पिताजी का पिता और केशर देवी को पिताजी की धर्मपत्नी माना गया है। गलत हो तो `script.js` में सुधारें।
- `year` (वर्ष) तय होने पर ही भरें; तब तक "तारीख याद रखें" बटन केवल सूचना दिखाएगा।
- **रास्ता देखें** अभी "बाफना मंगलम, दुर्ग" की Google Maps खोज खोलता है। सही स्थान का Google Maps लिंक मिलने पर उसे `mapsUrl` में डालें।
- **शुभ ध्वनि:** अपनी mp3 फ़ाइल रिपॉज़िटरी में डालें और `audio: "नाम.mp3"` भरें। खाली रहने पर बटन छिपा रहता है।

## 3. वास्तविक आगंतुक संख्या (GoatCounter)
GitHub Pages में काउंटर नहीं होता, इसलिए निःशुल्क सेवा GoatCounter (goatcounter.com) का उपयोग है। यह कुकी नहीं लगाती और व्यक्तिगत पहचान एकत्र नहीं करती।
1. goatcounter.com पर साइन अप करें; आपका कोड (जैसे `yadav-vivah`) आपके पते `yadav-vivah.goatcounter.com` में होगा।
2. GoatCounter में **Settings → Site** खोलकर **"Allow adding visitor counts on your website"** चालू करें (डिफ़ॉल्ट रूप से बंद रहता है)।
3. `script.js` में `goatCounterCode: "yadav-vivah"` भरें और दोबारा अपलोड करें।

कोड खाली रहने या सेवा न मिलने पर "आगंतुक संख्या अभी उपलब्ध नहीं है" दिखता है; कोई नकली संख्या नहीं। GoatCounter आगंतुकों की गिनती देती है, इसलिए पृष्ठ पर "देखने वाले" लिखा है।

## 4. QR कोड बनाना
1. पहले ऊपर वाला **स्थायी** GitHub Pages लिंक खोलकर जाँचें कि साइट चल रही है।
2. कोई निःशुल्क QR जनरेटर (जैसे qr-code-generator.com या Google Chrome में *Share → Create QR code*) खोलें।
3. वही लिंक डालें, **PNG या SVG** डाउनलोड करें और निमंत्रण कार्ड पर छापें।
4. छापने से पहले फ़ोन से स्कैन करके जाँचें। किसी अस्थायी preview लिंक का उपयोग न करें।
